\chapter{Sensitivity Conjecture}

\section{The Problem}

\subsection{Informal}

\textbf{Background.} A Boolean function takes a string of bits (0s and 1s) and outputs a single bit. Several measures describe how complex such a function is. One measure, called sensitivity, asks: what is the most input bits you could flip at once to force the output to change? Another measure, called block sensitivity, asks the same question but allows you to flip whole blocks of bits together.

\textbf{Given.} You are given any Boolean function that takes $n$ input bits and produces one output bit.

\textbf{Goal.} Determine whether block sensitivity is always bounded by a polynomial in sensitivity. That is, if the sensitivity is $s$, must the block sensitivity be at most $s^c$ for some fixed constant $c$?

\textbf{Constraints.} The function can be any mapping from $\{0,1\}^n$ to $\{0,1\}$---there are no restrictions on its form. The bound must hold for all $n$ and all Boolean functions. The constant $c$ must not depend on $n$ or on the specific function.

\textbf{Example.} Consider the parity function: it outputs 1 if an odd number of input bits are 1, and 0 otherwise. Flipping any single bit always changes the output, so the sensitivity is 1. But you can also flip blocks of bits---for instance, flipping all $n$ bits at once always changes the output, so the block sensitivity is at least $n$. The question is whether this gap (sensitivity 1 versus block sensitivity $n$) can ever be worse than polynomial.

\subsection{Formal}
\begin{conjecture}[Nisan-Szegedy, 1992]
$s(f)$ and $bs(f)$ are polynomially related: $bs(f) \le s(f)^c$ for some constant $c$.
\end{conjecture}

\subsection{Historical Context}
The sensitivity conjecture stood for 27 years, resisting attacks from Fourier analysis, probability theory, and complexity theory. It was one of the oldest open problems in theoretical computer science.

\subsection{What Was Known}
The conjecture was posed by Nisan and Szegedy in 1992. For decades, attempts to prove it used Fourier analysis, probability theory, and algebraic approaches---all without success. The best known bound was exponentially weaker than the conjectured polynomial relationship. The problem was considered one of the most important open questions in complexity theory.

\subsection{Why It Matters}
The sensitivity conjecture is about measuring the complexity of yes-or-no questions---a fundamental concept in computer science. If two different ways of measuring complexity are always closely related, it means that the complexity of a problem is a robust notion, not an artifact of how you choose to measure it. This has implications for algorithm design and the theory of computation.

\subsection{Simplified Version}
For the parity function $f(x_1, \ldots, x_n) = x_1 \oplus \cdots \oplus x_n$ (which outputs 1 if an odd number of bits are 1), the sensitivity is $\sqrt{n}$ while the block sensitivity is $n$---a quadratic gap. The conjecture asserted that this gap is always at most polynomial: $bs(f) \le s(f)^c$ for some constant $c$. Huang's 2019 proof showed $c \le 4$, settling the question.

\section{Mathematical Theory}

\subsection{Prerequisites}
This chapter assumes familiarity with:
\begin{itemize}
\item Boolean functions ($f: \{0,1\}^n \to \{0,1\}$)
\item Spectral graph theory (eigenvalues of adjacency matrices)
\item Basic complexity theory (decision trees, polynomial degree)
\end{itemize}

\subsection{Boolean Function Complexity Measures}

The sensitivity conjecture concerns the relationship between several complexity measures of Boolean functions. For $f: \{0,1\}^n \to \{0,1\}$, the key measures are:

\begin{definition}[Sensitivity]
The \emph{sensitivity} $s(f)$ is the maximum, over all $x \in \{0,1\}^n$, of the number of coordinates $i$ such that flipping the $i$-th bit of $x$ changes the value of $f$.
\end{definition}

\begin{definition}[Block Sensitivity]
The \emph{block sensitivity} $bs(f)$ is the maximum number $k$ such that there exist disjoint non-empty sets of coordinates $B_1, \ldots, B_k$ with the property that for each $i$, flipping all bits in $B_i$ changes the value of $f$.
\end{definition}

\begin{definition}[Degree]
The \emph{degree} $\deg(f)$ is the degree of the unique multilinear polynomial $P$ over $\mathbb{R}$ such that $f(x) = P(x)$ for all $x \in \{0,1\}^n$.
\end{definition}

\begin{definition}[Decision Tree Depth]
The \emph{decision tree depth} $D(f)$ is the minimum depth of a deterministic decision tree that computes $f$.
\end{definition}

These measures are ordered: $s(f) \le bs(f)$, $s(f) \le \deg(f)$, $s(f) \le D(f)$. The conjecture asserted that all are polynomially related.

\subsection{The Hypercube and Its Spectrum}

The $n$-dimensional hypercube graph $Q_n$ has vertex set $\{0,1\}^n$ with edges between strings differing in exactly one coordinate. Its spectral theory is classical:

\begin{fact}
The eigenvalues of the adjacency matrix of $Q_n$ are $n - 2k$ for $k = 0, 1, \ldots, n$, with multiplicity $\binom{n}{k}$.
\end{fact}

The eigenspace for eigenvalue $n$ is spanned by the all-ones vector. The eigenspace for eigenvalue $n - 2$ is spanned by the $n$ coordinate functions $x_i$.

\subsection{Cauchy Interlacing}

The key tool in Huang's proof is a classical result about how eigenvalues change when restricting to a subgraph:

\begin{theorem}[Cauchy Interlacing]
If $A$ is an $n \times n$ symmetric matrix with eigenvalues $\lambda_1 \ge \cdots \ge \lambda_n$, and $B$ is an $(n-1) \times (n-1)$ principal submatrix with eigenvalues $\mu_1 \ge \cdots \ge \mu_{n-1}$, then:
\[
\lambda_1 \ge \mu_1 \ge \lambda_2 \ge \mu_2 \ge \cdots \ge \mu_{n-1} \ge \lambda_n.
\]
\end{theorem}

This means that restricting to a subgraph can only push eigenvalues inward, but the largest eigenvalue can decrease by at most the gap between the two largest eigenvalues.

\subsection{Signings and Hadamard Matrices}

A \emph{signing} of a graph $G$ is an assignment of $\pm 1$ to each edge, producing a signed adjacency matrix $A_G$. Huang's key construction produces a signing of $Q_n$ such that:

\begin{fact}
There exists a signing of $Q_n$ such that $A^2 = nI$, making $A$ proportional to a Hadamard matrix.
\end{fact}

This is the crucial ingredient: it means the signed hypercube has all eigenvalues equal to $\pm\sqrt{n}$, giving maximum spectral gap.

\section{The Solution}

\subsection{The Big Idea}
Think of the Boolean hypercube as a giant network where each corner is a string of $n$ zeros and ones, and two corners are connected if they differ in exactly one bit. The question is: if flipping a few bits always changes the function's answer, must flipping \emph{bigger groups} of bits also be effective? Huang's genius was to *redraw the network* with carefully chosen signs on the edges (like coloring them red or blue) so that the network becomes perfectly balanced---every ``frequency'' has the same magnitude. Then he used a classical theorem (Cauchy interlacing) to show that any subset of corners that the function labels as ``1'' must contain at least $\sqrt{n}$ connections. This single observation, from a one-page argument, was enough to settle a 27-year-old conjecture. The insight is that *spectral balance is the key*: if you can make every eigenvalue the same size, then any subset must have a large edge boundary.

\subsection{What Was Stopping Progress}
For 27 years, three major families of techniques failed. Fourier analysis could express sensitivity in terms of Fourier coefficients but could not extract polynomial bounds. Decision tree arguments gave $s(f) \leq D(f)$ but could not connect $D(f)$ back to $bs(f)$ polynomially. Hypercontractivity gave bounds on influence but could not improve beyond the exponential barrier. Each approach hit the same wall: the tools were strong enough to relate sensitivity to \emph{some} complexity measure, but not strongly enough to close the polynomial gap. The problem required a fundamentally different angle.

\subsection{The Breakthrough}
Huang's proof introduced one key idea: the \emph{signed hypercube}. The standard hypercube $Q_n$ has eigenvalues $n, n-2, \ldots, -n$---a wide spread. Huang constructed a signing of $Q_n$ such that $A^2 = nI$, meaning all eigenvalues are $\pm\sqrt{n}$. This is essentially a Hadamard matrix. Applying Cauchy interlacing to the subgraph induced by $f^{-1}(1)$ forces $s(f) \geq \sqrt{\deg(f)}$, from which $bs(f) \leq s(f)^4$ follows by standard reductions. The entire proof is just two pages.

\subsection{How It Works}

By the time of Huang's work in 2019, the best known bound relating block sensitivity to sensitivity was $bs(f) \leq 2^{s(f)}$---an exponential bound. The conjecture asserted that $bs(f) \leq s(f)^c$ for some constant $c$; in other words, the relationship should be polynomial, not exponential. The gap was enormous: going from exponential to polynomial. For the parity function on $n$ bits, the sensitivity is $\sqrt{n}$ and the block sensitivity is $n$, so the known exponential bound $2^{\sqrt{n}}$ was wildly loose. What was missing was any technique that could bridge the gap from exponential to polynomial.

Three major families of techniques had been tried over 27 years without success. Fourier analysis could express sensitivity in terms of Fourier coefficients but could not extract polynomial bounds from them. Decision tree arguments gave $s(f) \leq D(f)$ (sensitivity bounded by decision tree depth) but could not connect $D(f)$ back to $bs(f)$ polynomially. Hypercontractivity, a powerful tool in Boolean function analysis, gave bounds on influence and noise sensitivity but could not improve beyond the exponential barrier. Each approach hit the same wall: the tools were strong enough to relate sensitivity to \emph{some} complexity measure, but not strongly enough to close the polynomial gap. The problem required a fundamentally different angle.

Huang's proof introduced one key idea: the \emph{signed hypercube}. The standard hypercube $Q_n$ has adjacency matrix with eigenvalues $n, n-2, \ldots, -n$---a wide spread. Huang constructed a \emph{signing} (assigning $\pm 1$ to edges) of $Q_n$ such that the signed adjacency matrix $A$ satisfies $A^2 = nI$, meaning all eigenvalues are $\pm\sqrt{n}$. This is essentially a Hadamard matrix. He then applied the Cauchy interlacing theorem to the subgraph induced by $f^{-1}(1)$: since the signed hypercube has all eigenvalues at $\pm\sqrt{n}$, the induced subgraph must have an eigenvalue $\geq \sqrt{n}$, which implies minimum degree $\geq \sqrt{n}$. This gives $s(f) \geq \sqrt{\deg(f)}$, from which $bs(f) \leq s(f)^4$ follows by standard reductions. The entire proof is just two pages.

\begin{theorem}[Huang \cite{huang2019}]
$s(f) \ge \sqrt{\deg(f)}$, hence $bs(f) \le s(f)^4$.
\end{theorem}

Huang's proof is famously short (2 pages) and uses only spectral graph theory:

\begin{enumerate}
\item Consider the $n$-dimensional hypercube graph $Q_n$, whose vertices are $\{0,1\}^n$ and edges connect strings differing in one coordinate.
\item Construct a signing of the adjacency matrix $A$ of $Q_n$ such that $A^2 = nI$ (a Hadamard matrix structure).
\item By the Cauchy interlacing theorem, the subgraph induced by $f^{-1}(1)$ has an eigenvalue $\ge \sqrt{n}$.
\item This implies the subgraph has minimum degree $\ge \sqrt{n}$, so $s(f) \ge \sqrt{n}$.
\item Since $\deg(f) = n$ for the parity function, $s(f) \ge \sqrt{\deg(f)}$.
\end{enumerate}

\begin{highlightbox}
Huang's proof resolved a 27-year-old problem using a single clever idea: a signing of the hypercube's adjacency matrix. The proof uses no Fourier analysis, no probability, and no complexity theory---just linear algebra.
\end{highlightbox}

\subsection{After the Proof}

The sensitivity conjecture is settled: block sensitivity is polynomially related to sensitivity. Huang proved $bs(f) \le s(f)^4$, confirming the qualitative statement that Nisan and Szegedy conjectured in 1992. The question of whether these measures are polynomially related---versus exponentially related---has a definitive answer.

But the exact polynomial is still unknown. Huang's proof gives the exponent 4, meaning $bs(f) \le s(f)^4$. The conjectured truth is $bs(f) \le s(f)^2$, a quadratic relationship. For the parity function on $n$ bits, sensitivity is $\sqrt{n}$ and block sensitivity is $n$, so the quadratic bound would be tight. Whether the exponent can be reduced from 4 to 2 is a major open question. Some progress has been made on special classes of functions, but the general case remains open.

The signing technique that Huang introduced---constructing a Hadamard-like signing of the hypercube's adjacency matrix to maximize spectral gap---has been applied to other graph-theoretic problems. It connects to questions about induced subgraphs of the hypercube, spectral graph theory, and the structure of Boolean function complexity landscapes. The broader picture of how all the complexity measures (sensitivity, block sensitivity, certificate complexity, decision tree depth, degree, and others) relate to each other is better understood but still not complete.

\section{Impact}
\begin{itemize}
\item \textbf{Complexity theory}: Established polynomial relationships between all known boolean function complexity measures.
\item \textbf{Spectral methods}: The signing technique has been applied to other graph-theoretic problems.
\item \textbf{Open question}: The exact polynomial relating $s(f)$ and $bs(f)$ remains unknown---Huang's proof gives $c = 4$, but the conjectured value is $c = 1$.
\end{itemize}

\section{Computational Verification}

The sensitivity conjecture can be explored computationally by computing sensitivity, block sensitivity, and degree for all Boolean functions on small numbers of variables.

\subsection{Computing Complexity Measures}

\begin{verbatim}
from itertools import product

def truth_table(n):
    """Generate all 2^n inputs for n variables."""
    return list(product([0, 1], repeat=n))

def sensitivity(f, n):
    """Compute sensitivity of Boolean function f: {0,1}^n -> {0,1}."""
    s = 0
    for x in truth_table(n):
        val = f(x)
        count = 0
        for i in range(n):
            y = list(x)
            y[i] = 1 - y[i]
            if f(tuple(y)) != val:
                count += 1
        s = max(s, count)
    return s

def block_sensitivity(f, n):
    """Compute block sensitivity of Boolean function f."""
    bs = 0
    for x in truth_table(n):
        val = f(x)
        # Try all non-empty subsets of coordinates
        for mask in range(1, 2**n):
            blocks = [i for i in range(n) if mask & (1 << i)]
            y = list(x)
            for i in blocks:
                y[i] = 1 - y[i]
            if f(tuple(y)) != val:
                bs = max(bs, bin(mask).count('1'))
    return bs

# Parity function
def parity(x):
    return sum(x) % 2

n = 4
print(f"Parity on {n} bits:")
print(f"  sensitivity s(f) = {sensitivity(parity, n)}")
print(f"  block sensitivity bs(f) = {block_sensitivity(parity, n)}")
print(f"  bs/s^4 = {block_sensitivity(parity, n) / sensitivity(parity, n)**4}")
\end{verbatim}

\subsection{Exhaustive Search for Small $n$}

\begin{verbatim}
def all_boolean_functions(n):
    """Enumerate all 2^(2^n) Boolean functions on n variables."""
    inputs = truth_table(n)
    for bits in product([0, 1], repeat=2**n):
        f = lambda x, b=bits: b[sum(x[i] * 2**i for i in range(n))]
        yield f

def census(n):
    """Compute s(f), bs(f), deg(f) for all Boolean functions on n variables."""
    results = []
    for f in all_boolean_functions(n):
        s = sensitivity(f, n)
        bs = block_sensitivity(f, n)
        results.append((s, bs))
    return results

# Full census for n=3
print("n=3: all Boolean functions")
print(f"  Total functions: {2**(2**3)}")
for s, bs in sorted(set(census(3))):
    print(f"  s(f)={s}, bs(f)={bs}, bs/s^4={bs/s**4 if s > 0 else 'inf':.3f}")
\end{verbatim}

\subsection{Verifying Huang's Bound}

Check that $bs(f) \leq s(f)^4$ holds for all Boolean functions up to $n=4$.

\begin{verbatim}
for n in range(1, 5):
    max_ratio = 0
    for s, bs in census(n):
        if s > 0:
            ratio = bs / s**4
            max_ratio = max(max_ratio, ratio)
    print(f"n={n}: max bs/s^4 = {max_ratio:.4f} (must be <= 1)")
\end{verbatim}

Students should run these scripts to observe: (1)~the parity function achieves the maximum gap between $s(f)$ and $bs(f)$, (2)~Huang's bound $bs(f) \leq s(f)^4$ holds for all functions, and (3)~the census reveals the full landscape of complexity measure relationships.
\end{highlightbox}
